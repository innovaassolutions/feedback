# Rebuild guide: your first workflow

This guide walks through rebuilding the sample workflow on your own project.

## Finding your project ID

Open your project in the browser. The project ID is the long code in the address bar after /projects/. Copy it from there.

## Get Document Data

Add the Get Document Data step and choose the uploaded document. It pulls the fields you need out of the file.

## Core Agent

Configure the Core Agent with the extracted fields. Give it the instructions from the sample and test it with one document.

## Link Generator

Use the Link Generator to create a share link for the results. Links expire after seven days.

## Known problems

Some learners couldn't sign in to the training workspace at the start. If you can't sign in, ask the instructor to resend your invitation.
